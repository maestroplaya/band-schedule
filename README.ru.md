# Простой способ отслеживать расписание вашей группы

Надоело вручную добавлять тайм-слоты в свой онлайн-календарь?  
Что ж, вы попали по адресу!

> С чего начать?

Это очень просто, и всё делается прямо в GitHub:

1. **Сделайте форк этого репозитория (кнопка в правом верхнем углу страницы)**

https://github.com/user-attachments/assets/5437ee40-5631-4660-99ed-a13384b8c0f0

2. **Перейдите во вкладку Actions и включите workflows**

https://github.com/user-attachments/assets/2577bf78-d3a9-4529-8c58-1fc257965474

3. **Настройте переменную окружения (алиасы участников группы)**

https://github.com/user-attachments/assets/d2aa765a-2bd4-473c-948e-ce0972447df8

4. **Настройте Pages на использование GitHub Actions**

https://github.com/user-attachments/assets/2ec65b56-d4fa-4619-871a-b9f62350bebb

5. **Запустите workflow один раз вручную**

https://github.com/user-attachments/assets/51e6e7fb-cddf-47fd-8564-b4744368a485

6. **Скопируйте URL календаря**   
   Итоговый адрес будет выглядеть так:  
   `https://<your-nickname>.github.io/band-schedule/schedule.ics`  
   (как показано в видео, в разделе _Complete job_, но с добавлением schedule.ics в конце)  

Готово! Не стесняйтесь сообщать об ошибках и предлагать новые функции <3
